# 抖音网页版精简版（douyin-pure）

一个油猴脚本：精简抖音网页版首页，去掉顶栏和左侧栏、过滤广告与弹窗，把搜索栏移到左下角悬浮，并在左下角补回频道导航。播放控制条、设置按钮、点赞、评论、作者头像等互动元素全部保留。

## 功能

- **去顶栏**：隐藏 `#douyin-header` 及顶部组件。
- **去左侧栏**：隐藏 `#douyin-navigation`，内容区自动铺满整屏。
- **频道导航（关键）**：左下角悬浮「推荐 / 精选 / 关注 / 朋友」按钮，当前频道高亮，替代被隐藏的左栏入口。**切换时直接点击抖音左栏里的原生 tab**（`.tab-recommend` 等），走抖音自己的路由，而不是靠 URL 参数——因为抖音现在会把 `?recommend=1` 重写回精选页，靠网址跳转已不可靠。找不到原生 tab 时才回退到 URL 跳转。
- **自动进入推荐流**：打开首页（`/` 或 `/jingxuan`）时自动点击原生「推荐」tab；原生 tab 由 React 渲染、可能晚于脚本，故轮询等待最多约 10 秒。手动点过频道或被浏览器记录过自动进入后不会再自动切。若想保留「打开即精选」，把源码里的 `AUTO_RECOMMEND` 改为 `false`。
- **过滤广告**：登录引导弹窗、下载客户端弹窗/横幅、带广告标记的卡片、推广卡。
- **搜索栏移位**：左下角悬浮一个半透明搜索框，回车或点「搜索」跳转到抖音官方搜索页（鼠标移入变清晰）。
- **完整保留**：播放/暂停、进度条、音量、清晰度与设置菜单，右侧点赞/评论/收藏/分享、作者头像与视频信息。

## 安装

1. 安装 ScriptCat / Tampermonkey / Violentmonkey。
2. 把本目录下的 `douyin-pure.user.js` 拖入浏览器确认安装，或在脚本管理器中粘贴源码。已安装旧版的请更新脚本，否则频道切换仍走失效的 URL 参数。
3. 打开 `https://www.douyin.com/` 会自动进入推荐流；左下角可随时切回精选/关注/朋友。

> 与 pure-live 是两个独立脚本：本脚本作用于 `www.douyin.com`（首页推荐流），pure-live 作用于 `live.douyin.com`（直播间）等四个直播站。可同时安装，互不冲突。

## 本地验证

```bash
# 在仓库根目录
node --test douyin-pure/tests/pure.test.mjs
```

22 项测试覆盖：元数据、隐藏项、保留项不被误伤、搜索栏结构与跳转、频道导航挂载、原生 tab 查找（含被 CSS 隐藏时）、点击各频道派发原生鼠标事件序列且不改 URL、无原生 tab 时回退 URL、高亮、幂等挂载、自动进入推荐的触发/跳过条件、非首页不自动跳等。

## 适配说明

抖音网页改版较频繁：

- **隐藏规则**集中在源码 `PURE_STYLE` 数组，按注释分区（1 顶栏/左栏、2 内容区、3 广告、4 搜索栏、5 频道导航），定位到新选择器后替换对应项即可。
- **频道切换**依赖左栏原生 tab 的 class（`.tab-recommend` / `.tab-discover` / `.tab-follow` / `.tab-friend`），集中在 `CHANNELS` 数组的 `tabs` 字段。若抖音改了 tab 的 class，只改这里即可；`href` 是找不到原生 tab 时的兜底地址。
- **搜索栏**定位在第 4 区 `.douyin-pure-search`（当前 `left:16px; bottom:18px`），频道导航在第 5 区（当前 `bottom:62px`，紧贴搜索栏上方）。
