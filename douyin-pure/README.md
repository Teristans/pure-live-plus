# 抖音网页版精简版（douyin-pure）

一个油猴脚本：精简抖音网页版首页推荐流，去掉顶栏和左侧栏、过滤广告与弹窗，并把搜索栏移到左下角悬浮；播放控制条、设置按钮、点赞、评论、作者头像等互动元素全部保留。

## 功能

- **去顶栏**：隐藏 `#douyin-header` 及顶部组件。
- **去左侧栏**：隐藏 `#douyin-navigation`，内容区自动铺满整屏。
- **过滤广告**：登录引导弹窗、下载客户端弹窗/横幅、带广告标记的卡片、推广卡。
- **搜索栏移位**：左下角悬浮一个半透明搜索框，回车或点「搜索」跳转到抖音官方搜索页（默认鼠标移入变清晰）。
- **完整保留**：播放/暂停、进度条、音量、清晰度与设置菜单，右侧点赞/评论/收藏/分享、作者头像与视频信息。

## 安装

1. 安装 ScriptCat / Tampermonkey / Violentmonkey。
2. 把本目录下的 `douyin-pure.user.js` 拖入浏览器确认安装，或在脚本管理器中粘贴源码。
3. 打开 `https://www.douyin.com/` 即自动生效。

> 与 pure-live 是两个独立脚本：本脚本作用于 `www.douyin.com`（首页推荐流），pure-live 作用于 `live.douyin.com`（直播间）等四个直播站。可同时安装，互不冲突。


测试覆盖：元数据、隐藏项、保留项不被误伤、搜索栏结构与幂等挂载、搜索 URL 编码与跳转、`GM_addStyle` 缺失回退、DOMContentLoaded 启动路径。

## 适配说明

抖音网页改版较频繁，若某天部分隐藏项失效，通常是选择器变化。本脚本的隐藏规则集中在源码 `PURE_STYLE` 数组，按注释分区（1 顶栏/左栏、2 内容区、3 广告、4 搜索栏），定位到新选择器后替换对应项即可。若搜索栏位置想调整，改第 4 区的 `.douyin-pure-search` 定位属性（当前为 `left:16px; bottom:18px`）。
