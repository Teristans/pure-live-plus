# 抖音网页版精简版（douyin-pure）

一个油猴脚本：精简抖音网页版首页，去掉顶栏和左侧栏、过滤广告与弹窗，把搜索栏移到左下角悬浮，并在左下角补回频道导航（左栏隐藏后就靠它切换频道）。播放控制条、设置按钮、点赞、评论、作者头像等互动元素全部保留。

## 功能

- **去顶栏**：隐藏 `#douyin-header` 及顶部组件。
- **去左侧栏**：隐藏 `#douyin-navigation`，内容区自动铺满整屏。
- **频道导航**：左下角悬浮一组「推荐 / 精选 / 关注 / 朋友」按钮，替代被隐藏的左侧栏入口，当前频道高亮；点过的选择会记住，不会被自动跳转覆盖。
- **默认直达推荐**：抖音根路径 `/` 实际是「精选」页，脚本会自动跳到 `https://www.douyin.com/?recommend=1`（推荐流）。若想保留「打开即精选」，把源码里的 `AUTO_RECOMMEND` 改为 `false` 即可，频道导航照常可用。
- **过滤广告**：登录引导弹窗、下载客户端弹窗/横幅、带广告标记的卡片、推广卡。
- **搜索栏移位**：左下角悬浮一个半透明搜索框，回车或点「搜索」跳转到抖音官方搜索页（鼠标移入变清晰）。
- **完整保留**：播放/暂停、进度条、音量、清晰度与设置菜单，右侧点赞/评论/收藏/分享、作者头像与视频信息。

## 安装

1. 安装 ScriptCat / Tampermonkey / Violentmonkey。
2. 把本目录下的 `douyin-pure.user.js` 拖入浏览器确认安装，或在脚本管理器中粘贴源码。已安装 1.0.0 的请更新脚本，否则没有频道导航。
3. 打开 `https://www.douyin.com/` 会自动进入推荐流；左下角可随时切回精选/关注/朋友。

> 与 pure-live 是两个独立脚本：本脚本作用于 `www.douyin.com`（首页推荐流），pure-live 作用于 `live.douyin.com`（直播间）等四个直播站。可同时安装，互不冲突。

## 适配说明

抖音网页改版较频繁，若某天部分隐藏项失效，通常是选择器变化。隐藏规则集中在源码 `PURE_STYLE` 数组，按注释分区（1 顶栏/左栏、2 内容区、3 广告、4 搜索栏、5 频道导航），定位到新选择器后替换对应项即可。频道地址集中在 `CHANNELS` 数组，搜索栏定位在第 4 区 `.douyin-pure-search`（当前 `left:16px; bottom:18px`），频道导航在第 5 区（当前 `bottom:62px`，紧贴搜索栏上方）。
